# 💰 Expenses Dashboard | FY 2025

## 🚀 Project Overview

The **Expenses Dashboard FY 2025** is a premium financial analytics dashboard designed to monitor, analyze, and optimize enterprise expenses across departments, categories, payment methods, and budget performance.

This project demonstrates advanced **Business Intelligence**, **Data Visualization**, and **Financial Analytics** concepts using a modern dashboarding approach inspired by enterprise-grade BI platforms such as:

* Microsoft Power BI
* Tableau
* Looker Studio
* Enterprise CFO Dashboards

The dashboard provides actionable insights into:

* Department spending
* Budget allocation
* Expense trends
* Transaction monitoring
* Financial efficiency
* Approval analytics

---

# 🎯 Business Problem

Organizations often struggle with:

* Uncontrolled operational spending
